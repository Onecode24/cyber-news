"GitSpawn" flaws let a booby-trapped repo run code the moment an AI coding agent opens it

Researchers found that AI coding tools — including Claude Code, Codex, Cursor and Grok — can be tricked by a malicious .git/config into silently running attacker code while gathering background context, with no prompt or approval needed. Vendors are being urged to disable the abused Git setting during automatic context checks.

Beginner Pick

Not breaking news — a story worth understanding if you're new to security.

May 2021

The Colonial Pipeline attack: how one leaked password shut down fuel for the East Coast

In May 2021, the ransomware group DarkSide broke into Colonial Pipeline, which carries nearly half the fuel supply for the U.S. East Coast, using a single compromised VPN password for an account that didn't have multi-factor authentication enabled. Colonial didn't wait to find out how far the attackers had gotten inside its network — it proactively shut the pipeline down itself, which was the actual cause of the days of gas shortages and panic-buying that followed, not the hack itself.

The company ended up paying roughly $4.4 million in ransom, part of which the FBI later recovered by tracing the cryptocurrency wallet. The incident became the textbook example of how a single weak credential in a "boring" IT system can cascade into a national infrastructure crisis, and it directly pushed U.S. pipeline operators and other critical-infrastructure sectors into new mandatory cybersecurity regulations.

Why it matters for beginners: it's the clearest real-world case for two fundamentals you'll hear constantly — multi-factor authentication and network segmentation between IT and operational systems — and a reminder that the business decision after a breach can cause more visible damage than the breach itself.
