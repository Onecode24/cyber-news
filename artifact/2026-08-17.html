Beginner Pick — Learn the Fundamentals

The XZ Utils backdoor: how one engineer's curiosity stopped a supply-chain catastrophe

Not breaking news — a landmark near-miss from March 2024, worth knowing as you learn how software supply chains can be quietly poisoned.

XZ Utils is a small, unglamorous compression library used inside countless Linux systems — including, indirectly, OpenSSH, the tool most servers use for secure remote logins. Over roughly two years, a contributor going by "Jia Tan" built up trust in the project through legitimate-looking code contributions, eventually gaining co-maintainer access. In early 2024, that identity quietly slipped a sophisticated backdoor into XZ Utils versions 5.6.0 and 5.6.1, hidden inside test files and obfuscated build scripts, designed to let an attacker with the right secret key remotely execute code on affected servers.

It was caught almost by accident: Andres Freund, a Microsoft engineer working on unrelated database performance testing, noticed that SSH logins on a development machine were taking about half a second longer than they should. Instead of shrugging it off, he investigated — and traced the delay back to the tampered library, days before the backdoored versions reached major stable Linux distributions. The incident is now a textbook example of two ideas every beginner should sit with: open-source software's strength (anyone can contribute) is also a risk surface attackers can patiently exploit, and unglamorous human vigilance — noticing that something is just slightly slower or slightly off — remains one of security's most valuable defenses.
