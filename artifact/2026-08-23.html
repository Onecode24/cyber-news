Not breaking news — a foundational story worth knowing

The XZ Utils Backdoor

Discovered March 2024

In early 2024, a Microsoft engineer named Andres Freund noticed something odd: SSH logins on a server were taking a fraction of a second longer than usual. Chasing that tiny slowdown, he uncovered a backdoor hidden inside xz, a compression library used by nearly every Linux system on Earth, planted by a contributor who had spent over two years quietly building trust as a co-maintainer of the open-source project.

The backdoor was expertly hidden inside test files and build scripts, engineered to eventually let the attacker slip malicious commands past SSH authentication on affected systems. Had it not been caught days before major Linux distributions shipped it, it could have handed remote access to millions of servers worldwide.

It matters for beginners because it's the clearest real-world lesson in supply chain risk: the software you trust is often built on volunteer-maintained code with far less scrutiny than a bank or hospital website. It's also a reminder that good security sometimes comes down to one curious person noticing that something felt "slightly off" — and taking it seriously.

Why we picked it now: today's Rust crates incident above is a smaller-scale echo of the exact same playbook — compromise a trusted maintainer, hide malicious code in the build process. Worth keeping in mind any time you run npm install or cargo build.
